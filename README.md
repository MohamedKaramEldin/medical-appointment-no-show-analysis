# Medical Appointment No-Show Analysis

Why do some patients miss their medical appointments? In this project, I explore a dataset of over 100,000 appointments in Brazil and look for patterns in whether patients show up.

This personal project was part of the udacity data analysis program to mainly practice data cleaning, working with pandas, and exploratory data analysis. I look at different patterns such as age, gender, waiting time, neighborhoods etc., then use plots to compare attendance across these groups.

The notebook contains the questions, cleaning steps, analysis, and conclusions. This is an exploratory analysis, so the patterns do not establish what necessarily causes patients to miss appointments.

## Open the analysis

The dataset is included in the `data` directory and was provided by Udacity. The code and written analysis are my own coursework.
